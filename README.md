# Customer Churn Prediction

End-to-end machine learning project for predicting customer churn from structured customer data.

## Focus
- Data cleaning and validation
- Exploratory data analysis
- Feature engineering
- Classification modeling
- Model evaluation
- Reusable prediction pipeline

## Project structure

```text
customer-churn-prediction/
├── data/
├── notebooks/
├── src/
│   ├── data_loader.py
│   ├── preprocessing.py
│   ├── feature_engineering.py
│   ├── train.py
│   ├── evaluate.py
│   └── predict.py
├── models/
├── tests/
├── requirements.txt
└── README.md
```

## Prediction pipeline

The production-style prediction workflow applies the same preprocessing and feature transformations used during training before returning a churn probability and classification.
